# 演绎中断链路排查与修复（第63场后）

## 已确认的现场事实

- 第63场为 TASK_REBATE / 林晓，数据库状态为 INTERRUPTED / DIALOGUE_FAILED，第5轮没有保存骗子消息。
- 第4轮双方仍在约定关注截图及5元报酬，受害者尚未实际提交截图；不能把约定解释为已经完成任务或已经到账。
- 用户日志显示第5轮 SCAMMER 连续三次被 `fund quote is not a new executed action` 拒绝。被拒绝的原始JSON没有保存，不能断言实际触发的是中文金额、未来承诺、旧到账或特定动词。
- 第63场固定提示词为 SCAMMER 8、VICTIM 6、NARRATOR 7、EVENT 4。上一轮新增的 EVENT 5 未用于这场。现存会话不会自动替换已冻结的提示词。
- 只读查询结果保存在 backend/target/session-63-review.json；查询使用只读事务，未改业务记录。

## 此次修复

1. **公共纠错上下文**：SCAMMER / VICTIM / EVENT / NARRATOR 的解析、校验失败会把本次被拒绝的输出附到下一次纠错提示中，明确它不是已发生事实或指令。仅保存本次输出在内存，最多16000字符；不把原始输出写入异常消息或日志，不跨角色共享，不累计旧失败输出。模型调用失败没有原始输出时只传错误原因。请求次数仍由原有重试配置与剩余时间约束。
2. **公共解析反馈**：资金、语速、证据及等待事项枚举错误提供具体字段与合法枚举值；字段集合错误列出预期字段。仍拒绝未知值、错误字段与非法类型，不默认替换为成功或空事件。
3. **资金证据**：旧的单字“将”检查会误拒绝“已将5元转账”；现区分完成语境和未来语境。报酬认可“已经给你转了5元”等明确完成表达，付款及预留释放也必须具有完成证据。对这些动作同时检查引用所在的完整分句，防止从“没有实际转账5元”中截取“实际转账5元”记账。返款原有严格关联和完成校验保留。
4. **输出约束提前提示**：两个对话角色始终得到120字符上限、阿拉伯数字资金证据及完成动词约束。仅承诺、等待操作、查收历史款项不生成新资金动作；不得靠编造执行通过校验。
5. **等待事项证据**：NARRATOR 的 waitingUpdates.basis 在可重试的生成阶段就必须逐字来自本轮受害者消息；此前这个检查最晚会在保存阶段才失败，直接导致中断。数据库侧再次校验保留。
6. **后台异常收敛与诊断**：骗子异步准备中的非 AgentCallException 异常转成明确失败结果，避免异常 future 在 join 时反复抛错、拖到时限。数据访问异常归为 PERSISTENCE_FAILED，其余准备异常为 DIALOGUE_FAILED。EVENT、受害者准备、解说准备/保存及音频文件写入补充阶段日志；意外异常只记录类型与代码位置，不打印供应商或SQL载荷。校验日志增加角色、轮次、尝试号。
7. **分析保存纠错**：funds-v2/v3会话在最终分析保存时遇到业务校验拒绝，会把具体原因送回NARRATOR。生成失败与保存失败共用当前轮最终分析的调用额度（默认总计3次），不会每次保存失败都重置重试预算；重做后的future仍唤醒推进器。保存事务原有回滚和数据库侧校验保留。真实数据访问异常不走内容纠错。
8. **事件提交的状态竞争**：播放回执/暂停可在EVENT生成与提交之间改变stateVersion。对同一条已保存骗子消息的同一份候选，版本校验失败后重新读取状态并尝试提交一次，仍保留当前轮与版本检查。连续状态冲突按状态异常收敛，不再伪装成内容错误消耗模型重试。
9. **播放恢复竞态**：重新加载音频可能使初始 play Promise 以 AbortError 拒绝。恢复已接管后忽略初始 Promise 的过期失败回调，由恢复 Promise 和后续卡顿检查决定结果。仍只允许一次卡顿恢复，仅在真实 ended 后回执完成。

## 所有现有中断入口的检查结果

| 入口 | 检查结果与处理 |
| --- | --- |
| DIALOGUE_FAILED | 模型网络/空输出/截断、JSON/枚举/长度、资金/行动门槛、最低轮数重生成耗尽、保存时复核失败均可能触发。此次改公共纠错、资金表达、字段反馈及异步异常；持续非法输出仍须停止，不能伪造对话或账目。 |
| ANALYSIS_FAILED | EVENT、NARRATOR 生成与保存，材料、原文证据、结局一致性、等待事项均有校验。保留前次V27/V28修复，并补共同纠错、等待依据前置检查、阶段日志。等待事项缺失或非法状态迁移等保存拒绝现在进入剩余最终分析纠错额度；额度耗尽仍停止，不静默吞掉。 |
| TTS_FAILED | Qwen请求、音频下载/格式、合成时限、临时音频写入、缺失音频均可能触发。已有有限重试与剩余时间约束；本次补写入失败日志。未调用真实语音。 |
| MEDIA_FAILED | 前端开场动画失败、音频加载/播放错误、持续卡顿经FAILED回执触发。补初始播放与恢复的异步竞态；持续媒体错误仍终止，不能发送假COMPLETED。 |
| PERSISTENCE_FAILED | 数据库访问/保存失败必须停止，避免对话、流水、状态分裂。补异步骗子准备的数据访问异常归类。未进行实库故障注入。 |
| CONNECTION_LOST | 检查断流宽限、最近客户端活动与剩余播放时间的联合条件；单次SSE断流不直接中断。未修改规则，未做断网实测。 |
| TIME_LIMIT | 服务端定时器/扫描按剩余有效时间收敛；完整轮次与未完成轮次处理不同。保留规则，未延长时限或无限重试。 |
| USER_EXIT | 主动离开、退出登录或登录会话销毁触发；不是模型生成故障。 |
| SERVICE_RESTARTED | 服务重启后运行中会话失去执行上下文，按既有规则终止并清理临时音频。 |
| FUNDS_EXHAUSTED / CHARACTER_EXIT | 资金真实不足或角色退出的业务终止；不得改成假付款、假继续。 |

报告生成在演绎结束后独立处理，不是第63场第5轮 DIALOGUE_FAILED 的入口。本次未改报告流程或既有迁移文件。
