# 每轮信任分展示（2026-10-26）

按用户最新要求，观看页解说增加信任分开始值、结束值及净变化，例如“65 → 70，本轮 +5 分”。此项覆盖旧规格中禁止向用户接口披露信任分的限制；阈值、系数和事件明细仍不公开，骗子、受害者的模型输入保持隔离。

## 实现

- `Analysis.trustChange` 包含 `before`、`after`、`delta`，HTTP 状态、analysis.saved SSE 及共用 Analysis 的历史接口口径一致。
- 从初始信任分与已保存事件按轮次计算，不读取会话最新分数代替历史分数。包含本轮事件判定与最终态度判定；净变化使用裁剪后的实际分差。
- 无事件轮次继承上一轮分数，变化为 0；没有初始信任分的旧会话返回 null；未完成解说时不提前显示本轮分数。
- 页面在原解说区域展示，风险档位仍独立显示，并标明“仅供观看，角色不可见”。未记录信任分时明确提示，不补造数据。
- 不修改任何模型提示词，不增加模型调用、依赖、数据表或迁移。后端重启、前端刷新后生效。
