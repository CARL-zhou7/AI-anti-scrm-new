# V1.2 阶段 2 完成报告

范围：会话快照 v2、初始资金、状态/历史读取及历史资金摘要。分支 `feature/v1.2`，起点 `a12bea3`。用户已确认进入阶段 2；阶段 3 仍须另行确认。

## 本次编码修改了什么

- V8：新增会话七个资金字段、轮次六个资金字段和 `simulation_fund_flow` 表，包含外键、顺序唯一、正金额、类型/用途组合、预留释放理由及实际亏损约束。仅修改新行的快照版本默认值，旧行仍为 1。
- 快照：新受害者快照保存基础事实、金额、三套场景资料及 `selected_scenario_code`；写入前检查三套完整性。历史读取只使用冻结 JSON，缺字段返回 null/空列表。后台更新已有父行写锁，开始使用父行读锁，保持画像和子资料的一致性。
- 初始化：新会话显式写 `snapshot_schema_version=2`，初始资金和余额均取画像可动用资金，其他金额/次数为 0。新轮次保存当前余额，避免把数据库默认 0 当作余额耗尽。
- 状态/历史：State 增加 Funds；HistoryDetail 增加 Funds 和 rulesetVersion；HistoryRound 增加资金摘要。旧会话 `fundsRecorded=false`、金额/次数全部 null、旧轮次 funds=null。历史 flows=[]，状态 flows=null。
- 前端：添加 Funds/FundFlow 类型；历史详情展示七项摘要及轮次资金。旧记录显示“未记录”，真实 0 显示 0。实时舞台没有资金面板。
- 保留旧结果、旧报告和旧 Prompt；没有实现扣款、返款或资金流水写入，也没有修改已执行迁移、增加依赖或进入阶段 3。
