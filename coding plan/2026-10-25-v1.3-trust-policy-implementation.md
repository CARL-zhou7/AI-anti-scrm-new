# V1.3 信任分、行动门槛与报告范围 实施计划（修订版）

> 2026-10-26 高信任付款修订：普通费用变化、未补差额或垫付承诺争议，不自动等同确切反证，也不自动覆盖已经形成的合法付款决定；没有新请求时不自行付款。免费体验仅限定当次范围，后续出资需明确且不反复推翻同任务承诺。详见 `docs/2026-10-26-high-trust-payment-decision.md`。


> 2026-10-26 称呼修订：未知姓名不编姓，对方对自己的称呼不能照搬给对方；保留已建立的亲属关系，不因历史误称继续叫错。补充上下文必须保留称呼说明，角色隐私边界不扩大。详见 `docs/2026-10-26-address-direction-fix.md`。


> 2026-10-26 风险与主事件修订：风险是独立指标，综合信任与当前行为，行为相同时随信任升高而提高；不再直接等于信任分。亲友借款应沿用已建立主事件，不漂移为网贷催收、扣证或赎金剧情。详见 `docs/2026-10-26-story-boundary-and-independent-risk.md`。


> 2026-10-26 连续态度修订：付款资格保留硬门槛，但谨慎与接纳倾向须在同一付款区间逐分变化；当前风险改为随信任分连续变化，已受骗事实另行保留，不再将风险永久固定在某档。角色不接收实际信任分或门槛，生成侧表达控制不得写进人物认知。详见 `docs/2026-10-26-continuous-trust-behavior.md`。


> 2026-10-26 追加需求：小额转账后仍有继续可能时保留争取大额的剧情；明确拒绝追加、止损、识破并停止时结束，大额完成后也可正常结束。复盘及历史逐轮显示信任分，风险由同一组行动门槛联动；新增对话称呼与自然回应约束。此项修订此前“目标达成即立即结束”的解释，详见 `docs/2026-10-26-dialogue-trust-progression.md`。


> 2026-10-26 最少轮数修订：trust-v1 会话中，已通过资金、证据和场景目标校验的目标达成，可在前四轮正常结束；不能为了凑轮数丢弃合法付款。保存、结束与已有提前结束标记同步适用。详见 `docs/2026-10-26-early-goal-fix.md`。


> 2026-10-26 行为规则修订：信任分主导受害者行动，画像主要影响措辞；满足对应金额门槛、明确请求和资金条件时，应在本轮实际执行，不因一般谨慎不断新增核实前提。确切反证、资金限制与执行证据校验保留。此项覆盖此前弱倾向设计，详见 `docs/2026-10-26-trust-driven-actions.md`。


> 2026-10-26 用户需求修订：允许在观看页面的每轮解说中展示本轮开始、结束信任分及净增减，对应 `Analysis.trustChange`（HTTP/SSE 共用）。本文旧版“信任分不得出现在用户接口”的约束由此项覆盖；角色提示词仍不可接收信任分、阈值或系数。未记录分数的旧会话返回 null，其他内部信息仍不公开。实现说明见 `docs/2026-10-26-trust-display.md`。

## 阶段契约（可运行检查点，不是发布版本）

- 每个阶段结束：新场次能从开始走到结束并生成报告；只启用本阶段已完成的能力，未完成能力保持旧行为。
- **版本切换只在对应阶段发生**（模板版本另计：T9 发 V20、T17 发 V21、T20 发 V22，每次定稿后不再改）：
  | 阶段 | 切换项 | 不切换 |
  |---|---|---|
  | P1 | 只加列/表/约束，无 | 所有版本、默认值、提示词 |
  | P2 | `ruleset_version=PRD-V3.4`、`snapshot_schema_version=3`、信任参数与阈值冻结、SCAMMER/VICTIM/NARRATOR/EVENT 新版本 | `funds-v3`、报告 v3 |
  | P3 | `fund_ruleset_version=funds-v3`、报告 `content_schema_version=3`、REPORT v3（V21） | 正常业务结束报告范围仍保持旧行为 |
  | P4 | EVENT v2、NARRATOR v5（V22），等待事项接线 | 报告资格不变 |
  | P5 | 新增正常业务结束报告资格与结束原因投影 | 报告结构继续为 v3 |
  | P6 | 无 | 无 |
- P1～P2 新场次使用旧报告结构 v2；P3 的资金与报告 v3 同阶段完成后才验收，避免报酬净损失进入旧报告校验器。每场固定自身资金规则、报告结构及 Prompt；阶段切换不修改已保存会话。测试中新建隔离场次，不要求活动场次在线升级。
- 每个阶段结束暂停，等确认后进入下一阶段。
- 任务序号按实际执行顺序排列；V17～V19 属于 P1、V20 属于 P2、V21 属于 P3、V22 属于 P4。生成迁移前核对仓库中最大版本号；若已有新增迁移占号，顺延未创建的迁移并同步本文引用，不覆盖现有文件。
