# 知诈微信小程序

在 HBuilderX 中导入 `miniprogram`，在此目录运行 `npm ci`，再选择「运行 → 运行到小程序模拟器 → 微信开发者工具」。也可用 `npm run dev:mp-weixin` 编译，并在微信开发者工具中导入 `dist/dev/mp-weixin`。

本地导入时可在微信开发者工具的 AppID 栏选择「测试号」，并选择「不使用云服务」。HBuilderX 自动导入项目需要微信开发者工具的服务端口。

开发者工具默认直连 `http://127.0.0.1:8100/anti.scam/v1`，与网页开发代理指向同一个 Spring 服务。请从「注册普通用户账号」正式注册，两端都可登录同一普通账号并查看同一份历史。现有后端对每个账号只保留一个有效会话，切换端登录时之前的会话会失效。

体验版和真机环境在 `src/manifest.json` 配置对应的小程序 AppID，并在 `.env.local` 设置 `VITE_MINIPROGRAM_API_BASE=https://你的后端域名/anti.scam/v1` 后重新编译。域名应指向网页所用的同一套服务。微信后台需将其登记为请求和下载的合法域名，并恢复域名校验。

上传时运行 `npm run build:mp-weixin`，在微信开发者工具导入 `dist/build/mp-weixin`。该目录的打包配置显式包含新闻页文件。

首页的「查看原文」通过微信 `web-view` 打开公安官网。真机直达需要小程序账号支持网页容器，并在微信后台配置对应的业务域名（`gaj.wuhan.gov.cn`、`gaj.taizhou.gov.cn`）。原文加载失败时，可复制链接在浏览器查看。

模拟注册只保留当前页面内存中的输入，切换页面、提交练习或进入后台时清空。正式注册从登录页底部的「注册普通用户账号」进入。

## 验收

- 运行 `npm test` 检查登录会话轮换、CSRF 刷新、演绎回执选择及风险分档。
- 运行 `npm run build:mp-weixin` 检查页面和静态素材能正常编译。
- 在微信开发者工具检查模拟注册、普通登录、选角、演绎设置、魔法球、复盘、历史和资金流水。
